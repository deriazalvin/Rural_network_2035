# Projet Rural Network — Résumé

Ce dépôt contient une application complète pour la gestion et l'optimisation de tournées entre villages.

Fichiers clés :
- [STRUCTURE_PROJET.md](STRUCTURE_PROJET.md) — arborescence et explication des dossiers.
- [REALISATION.md](REALISATION.md) — ce qui a été implémenté.
- [GUIDE_UTILISATION.md](GUIDE_UTILISATION.md) — comment utiliser l'application.
- [DOCUMENT_TECHNIQUE.md](DOCUMENT_TECHNIQUE.md) — détails techniques et recommandations.
- [DEMARRAGE_RAPIDE.md](DEMARRAGE_RAPIDE.md) — commandes pour démarrer localement.

Aperçu technique :
- Frontend : React + Vite (fichiers dans la racine `src/`)
- Backend : Spring Boot (Java) dans `backend/`
- Algorithmes : Dijkstra et heuristiques d'optimisation implémentés en Java et JavaScript.

Prochaines étapes recommandées :
- Ajouter des tests unitaires et d'intégration.
- Documenter l'API (Swagger/OpenAPI).
- Conteneuriser avec Docker pour faciliter le déploiement.

Pour démarrer rapidement, voir : [DEMARRAGE_RAPIDE.md](DEMARRAGE_RAPIDE.md)
