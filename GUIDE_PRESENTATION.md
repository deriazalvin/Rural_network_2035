# Guide de présentation

Courtes suggestions pour présenter le projet (exposé, soutenance ou démonstration).

- Objectif : présenter le problème (gestion de tournées et routes pour villages) et la solution fournie (visualisation + optimisation).
- Plan recommandé :
  1. Contexte et besoin (2 min)
  2. Architecture globale (frontend / backend) — montrez `STRUCTURE_PROJET.md` (2 min)
  3. Démonstration en live :
     - Lancer le projet (préparé via `DEMARRAGE_RAPIDE.md`)
     - Créer quelques villages et routes
     - Lancer une optimisation et expliquer les résultats (5-7 min)
  4. Détails techniques clés : algorithmes (Dijkstra, optimisation de tournée), structures de données (Graphe, TasBinaire) (3-4 min)
  5. Limitations et axes d'amélioration (2 min)
  6. Questions / discussion (restant)

- Astuces live :
  - Préparer un jeu de données simple dans `insertion_donnees_demo.sql` pour éviter la saisie répétée.
  - Avoir la console backend et frontend visibles pour montrer les logs si nécessaire.
